# Домашняя работа №4: сшивка панорам

Программа строит отдельную панораму для каждой из трёх групп кадров
(`building1`, `building2`, `building3`).

## Метод

Основа — алгоритм с практического занятия:
ORB → `BFMatcher` + `knnMatch` с ratio test → `findHomography` (RANSAC) → `warpPerspective`.

Так как в группах 4–5 кадров, добавлено:

1. **Цилиндрическая проекция** каждого кадра перед поиском признаков — без неё края
   панорамы сильно растягиваются.
2. **Гомографии соседних пар**, приведённые к системе координат центрального кадра
   (ошибка не накапливается в одну сторону).
3. **Смешивание кадров** со взвешиванием по расстоянию до края кадра (мягкие швы),
   затем обрезка чёрных полей.

Подробное описание и обоснование параметров — в [REPORT.md](REPORT.md).

## Параметры

| Параметр | Значение |
|---|---|
| Число ORB-точек | 4000 |
| Ratio test | 0.80 |
| Порог RANSAC | 3.0 px |
| Фокус цилиндра (в долях ширины кадра) | 0.9; для `building3` — 1.5 |
| Размер кадров | уменьшаются до 1200 px по большей стороне |

Значения `ratio` и порога RANSAC подобраны перебором (`tune.py`).

## Установка и запуск

```
pip install -r requirements.txt
python panorama.py <папка_с_building1_building2_building3> building3=1.5
```

Панорамы сохраняются в той же папке: `panorama_building1.jpg`, `panorama_building2.jpg`,
`panorama_building3.jpg`. Готовые результаты лежат в `results/`.

Необязательные аргументы:
- `--debug` — сохранить картинки найденных совпадений в `<папка>/debug`;
- `building<N>=<число>` — задать фокус цилиндра для группы.

## Подбор параметров

```
python tune.py <папка_с_building1_building2_building3>
```

Скрипт перебирает `ratio` ∈ {0.65, 0.70, 0.75, 0.80} и порог RANSAC ∈ {2, 3, 4, 5} px
и выводит для каждой группы число инлайеров на самой слабой паре, среднюю долю инлайеров
и ошибку репроекции.

## Структура

```
panorama.py       # сшивка панорам
tune.py           # подбор параметров
requirements.txt
REPORT.md         # отчёт
results/          # итоговые панорамы
```
